# Figures

This directory contains the source photographs, measurement records, and publication-ready figures used in the accompanying paper.

## Directory structure

| Directory | Contents |
|---|---|
| `01-experimental-setup/` | Overall views of the robot, workspace, shielding panels, and camera support |
| `02-camera-mount/` | Camera mount close-ups and mounting-height measurements |
| `03-workspace-measurements/` | Physical measurements of the experimental workspace |
| `04-pvc-object/` | PVC-U cylinder, grip tape, and object-dimension measurements |
| `05-gripper-grasp/` | Mark 7 hand in open, pre-grasp, and cylinder-grasp configurations |
| `06-publication-figures/` | Final figures prepared for insertion into the paper |

Files in the numbered directories are original photographs. Their compressed image data has not been modified; filenames were changed to descriptive English names and GPS metadata was removed for public release. Publication figures are provided as PNG for preview or office documents, PDF for LaTeX, and SVG for vector editing where available.

## Naming convention

Directory and file names use lowercase English `kebab-case`. Related PNG, PDF, and SVG files share the same basename. Number suffixes distinguish alternate views of the same subject.

See [`06-publication-figures/README.md`](06-publication-figures/README.md) for figure captions, dimensions, and provenance notes.
